# Production extension

Mode: Operate. Extend the established production batch workflow for ingredient lists and traceable source lots. Include Inventory lot trace with recorded downstream lots, affected-order exposure, and an explicit recall-chain hold; source release never automatically releases descendants. Keep the incumbent visual system, navigation, quality release and evidence controls.

## Direction contract

THESIS: A production batch shows every issued ingredient and its lot evidence, so operators can explain actual output and safety release.

OWN-WORLD: Existing warm ruled operational rows, fig actions, porcelain surfaces, shared labelled fields, data tables and Fraunces drawer titles.

STORY: Define output and planned quantity, add independently measured input ingredients, execute once, inspect source lots and costs, review quality and release actual output. Failed release keeps the batch held; a safety lead can correct expiry with evidence.

FIRST VIEWPORT: Preserve Production's batch register. The creation drawer starts with batch reference, output and planned units, then expiry and input rows. Detail drawers retain state/actions, add issued lot rows and cost evidence, and label yield against planned output.

FORM: Narrow extension of the established production surface; no concept seed. Signature interaction: adding an ingredient keeps its unit and quantity together; execution turns those requirements into immutable issued lot rows. Inherited drawer motion and reduced-motion support.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
