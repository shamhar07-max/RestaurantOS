mess services, meal subscriptions, catering and production.

04 / Space, scale and small sizes

                                                              Clear space
                                                              Reserve at least 12% of visible icon height around standalone marks and lockups.
                                                              Supplied files include internal margin; keep additional surrounding content outside it.


                                                              Minimum recommendations
                                                              Standalone icon: 24 CSS px. Use flat favicon geometry at 16-32 px. Primary lockup:
                                                              360 CSS px. Compact lockup: 240 CSS px. Below this, display the icon with an
                                                              accessible text label.




These are practical starting points. Test the actual background, device and print method. Thin facet detail is decorative; the silhouette must remain
legible.
